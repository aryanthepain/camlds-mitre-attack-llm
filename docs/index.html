Architecture Workflow

How the AI Works in 3 Simple Steps

Instead of expecting analysts to manually cross-reference complex technical logs, the pipeline automates investigation through three distinct stages.

1

1. Alarm Ingestion

The network sensor spots abnormal packets and generates a raw log message containing signatures, destination ports, and protocol metadata.

Input: Suricata eve.json Network Log
2

2. AI Vector Search

The system converts the alarm into mathematical vectors and searches the MITRE ATT&CK encyclopedia to match the hacker's behavioral pattern.

Engine: SentenceTransformers + ChromaDB
3

3. Actionable Defense

A local reasoning model (Qwen 2.5) evaluates top matches and delivers a plain-English threat summary with exact defense steps.

Output: Verified Threat Report Card
