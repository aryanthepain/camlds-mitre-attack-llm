The Problem

Why Automated Alert Mapping Matters

SOC analysts face thousands of low-level IDS alerts daily. Translating them into actionable MITRE ATT&CK intelligence is manual, slow, and error-prone.

🔥

Alert Fatigue

SOC teams process 10,000+ alerts per day. Most are noise. Finding the real adversary behavior buried in Suricata signatures requires deep expertise and hours of manual triage.

🧩

Knowledge Gap

Mapping a raw network signature like "ET SCAN Nmap User-Agent" to ATT&CK technique T1046 (Network Service Discovery) requires both IDS expertise and ATT&CK fluency.

⚡

Speed Matters

Incident response depends on rapid classification. Automated mapping gives analysts an immediate ATT&CK-labeled view, accelerating triage and reducing mean time to respond.

How It Works

Pipeline Walkthrough

Run the entire pipeline with a single command — or step through each stage independently.

1

Download CAM-LDS Data

Fetch the raw manifestations archive from Zenodo containing Suricata eve.json network alert logs from controlled attack scenarios.

2

Prepare Alert Dataset

Parse all eve.json files, extract alert events, and build a clean JSONL dataset with signatures, categories, severity, protocols, and ground-truth MITRE labels.

3

Build MITRE ATT&CK Knowledge Base

Download the official MITRE ATT&CK Enterprise STIX JSON and parse 626+ technique documents with descriptions, detection guidance, and tactic mappings.

4

Create Vector Database

Encode all MITRE technique documents using SentenceTransformers and index them in ChromaDB for fast cosine similarity retrieval.

5

RAG Inference

For each alert, retrieve the top-k most similar MITRE techniques. In retrieval-only mode, predict the nearest. In LLM mode, pass candidates to Qwen 2.5 for contextual reasoning.

6

Evaluate & Report

Compute accuracy, precision, recall, F1, and top-k recall. Generate confusion matrices, classification reports, and a filled project report.

Note on baseline metrics: The retrieval-only baseline was evaluated on a small test slice (11 alerts, single technique class). Generic sentence embeddings underperform on infrastructure-level Suricata messages. The system is designed to improve through: (1) larger diverse test sets, (2) LLM reranking via Ollama, and (3) QLoRA fine-tuning — a Colab notebook is included in the repository.
